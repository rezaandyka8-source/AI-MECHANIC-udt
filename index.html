Cara Mendapatkan Gemini API Key Gratis

Ikuti 4 langkah mudah berikut (100% Gratis dari Google):

  1. Buka situs Google AI Studio: aistudio.google.com/app/apikey
  2. Login menggunakan akun Google / Gmail Anda.
  3. Klik tombol **"Create API Key"** (Buat Kunci API).
  4. Salin (copy) kode kunci yang berawalan AIzaSy... lalu tempelkan (paste) ke kolom di bawah ini.
